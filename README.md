# Jujutsu Kaisen Ultimate Minecraft Plugin

Jujutsu Kaisen Ultimate is a Minecraft plugin that brings the powers of Gojo Satoru, Sukuna, and Mahoraga to the game. This plugin includes custom items, entities, and abilities for each character, providing a unique and immersive experience for players. The plugin is designed to be compatible with Minecraft Bedrock Edition and includes all the required entity definitions, item definitions, scripts, textures, and animations.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. Obtain the custom items for each power by crafting or using commands.
2. Equip the items to activate the corresponding abilities.
3. Use the abilities in-game to fight against enemies and explore the world.
